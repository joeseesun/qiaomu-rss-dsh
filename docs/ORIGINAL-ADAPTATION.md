## 笔记与摘录适配边界

保留原版文章 Markdown 转换、保存位置窗口、文件/目录选择器、选文工具条、日期/模板格式及摘录去重。Host 文件目录默认 `DSH_HOME/qiaomu/qiaomu-rss-dsh/notes`，支持显式 `notesDir` 配置。只允许该目录下的 Markdown，禁止路径逃逸与内部符号链接；附件由 Host 下载并限制大小，重复保存使用独占新文件。日记正文保留用户手写内容，当前版本文章另存快照，用相对文件链接替换 Obsidian URI，跨阅读版本同一文章摘录归并。

Harness 没有暴露可靠的“当前笔记编辑器”API：原版追加能力改用原版文件选择器显式选择目标笔记，不猜测用户的活动文件。保存通知可通过已核对的 `sidebarRight.openResource` 在当前对话打开文件；无对话时明确提示，不擅自创建对话。原版模板日期/时间/标题替换支持，Templater 执行不在此接口中。

本轮新增 6 项笔记测试，加上原有 12 项原版集成测试；正文格式/安全清理、附件与重名、日记去重/用户内容/重启、目录和设置失败、保存清理、原版窗口/迟到卸载，以及完整 React 选文工具条回归已通过。尚无本轮真实 UI 证据，未发布或替换日用 RSS。
