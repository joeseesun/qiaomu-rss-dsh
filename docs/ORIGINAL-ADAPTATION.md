- 原版 RssSpeech、声音设置、播放控制、句子/单词高亮、选文朗读、继续进度、倍速和音色选择。Host 负责 RSS 状态和系统凭据；合成/音色/本机模型使用 Audio 0.1.1+ 公共接口，配置导入使用 Audio 0.1.2+。

- 原版 OutlineView/ArticleOutline，真实标题 DOM、层级、定位、滚动跟随；原版朱雀仿宋 FontFace 和许可。
- 原版 CSS 完整复制；原版主题色和筛选行结构复用。Host 样式映射 DSH token、弹窗原语和伴读/目录布局边界。
- Harness 原生伴读与会话上下文保留。没有调用付费 AI/语音。

## 验证

- 原有 RSS 全套测试通过；新增 12 项测试覆盖原版 DOM/选区范围、播放权、进度、选文不覆盖进度、卸载/重连迟到结果、密钥隔离、失败写入回滚和原 CSS 字节哈希。
- macOS 原版播放器经 Audio 公共 bridge 真实调用林飞，生成 462652 字节 PCM WAV，48 kHz 单声道，4.818833 秒。DOM 中模拟 Audio.play；不是物理扬声器验证。临时证据 `/tmp/qrs-audio-real-integration3.log`、`/tmp/qrs-rss-audio-0.wav`。
- 浏览器由用户控制，本轮没有操作浏览器、重启 QA 服务或日用 Harness。真实界面与公开安装包运行尚未验收。
